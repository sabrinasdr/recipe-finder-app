# Recipe finder
Recipe index made from a dataset with Supabase

## Features

Users can :
- see hover states for all interactive element
- see optimal layout for the interface depending on their device's screen size
- discover recipes by category : Popular, Vegan, Vegetarian, Dairy Free, Gluten Free
- search for a recipe
- filter search results by dish type or cuisine 

# Stack
- Html
- ReactJS
- NextJS
- Typescript
- Tailwindcss
- Database: Supabase
